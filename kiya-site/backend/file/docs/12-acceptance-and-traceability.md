# ۱۲ — ردیابی نیاز و آزمون پذیرش

> **به‌روزرسانی مالک:** [اصلاحیهٔ کیا](14-owner-addendum.md) و اسناد ۱۵ تا ۱۸ مقدم‌اند: برند KIYA، بنفش/طلایی، عمده در هسته و هدف نهایی FULL. نام‌ها/فازهای قبلی در این فایل تاریخی‌اند.

## کنترل کیفیت رابط
Loading/Empty/Error/Partial/Offline برای همهٔ صفحات؛ retry بدون پاک‌کردن فرم؛ skeleton هم‌اندازهٔ رسانه؛ sold-out و تنوع ناموجود؛ صفحهٔ 404/500 فارسی. حالت کم‌حرکتی، contrast AA، صفحه‌خوان و keyboard باید دستی هم بررسی شوند. شاخص‌های عملکرد با محیط/دستگاه ثبت شوند: هدف p75 موبایل LCP<2.5s، INP<200ms، CLS<0.05؛ این‌ها هدف‌اند نه نتیجهٔ اندازه‌گیری این بسته.

## تعریف پایان هر نسخه
تمام P0 نسخه سبز؛ P1های ناتمام با مسئول و تاریخ/تصمیم؛ بدون مسیر مالی یا امنیتی با mock؛ تأیید UI موبایل و دسکتاپ؛ migration روی DB خالی و upgrade؛ گزارش backup restore؛ مستند env، deploy، rollback و محدودیت‌های شناخته‌شده. screenshot صرفاً سند ظاهر است و جای integration test را نمی‌گیرد.
