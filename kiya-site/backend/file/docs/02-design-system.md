### ۱.۳ فاصله، شعاع، سایه، حرکت

- **شبکهٔ ۴px**؛ مقیاس: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- **شعاع:** `sm 8` (چیپ، ورودی) · `md 12` (کارت) · `lg 16` (کارت بزرگ، شیت) · `xl 24` (مودال) · `full 999` (استوری، آواتار، دکمهٔ گرد).
- **سایه:** `e1 0 1px 2px rgba(16,24,40,.06)` · `e2 0 4px 12px rgba(16,24,40,.08)` · `e3 0 16px 40px rgba(16,24,40,.12)` · `e4 0 32px 64px rgba(16,24,40,.18)` (مودال).
- **حرکت:** `fast 150ms`, `base 220ms`, `slow 320ms`؛ easing `cubic-bezier(.2,.8,.2,1)`. انیمیشن‌های کلیدی: بازشدن مودال (scale 0.96→1 + fade)، بازشدن «بیشتر» (height auto با opacity)، قلب لایک (scale 1→1.35→1)، اسکلتون (shimmer 1.4s).
- **احترام به `prefers-reduced-motion`**.

### ۱.۴ آیکون‌گرافی

- ست: **Lucide** (خط 1.75px، گوشه‌های گرد) + ۶ آیکون اختصاصی: قلبِ خرید، سبدِ استوری‌دار، بات، برچسب «خرید تأییدشده»، حلقهٔ کالکشن، کد تخفیف.
- آیکون‌های تجاری باید «پر» در حالت فعال باشند (مثل اینستاگرام).
- RTL: آیکون‌های جهت‌دار (فلش، ارسال) باید `scaleX(-1)` شوند.

## ۲. RTL و فارسی‌سازی — قواعد عملی

1. `dir="rtl"` روی `<html>`، `lang="fa-IR"`.
2. از **logical properties** استفاده کن: `padding-inline`, `margin-inline-start`, `inset-inline-end`.
3. **اعداد و تاریخ:** `Intl.DateTimeFormat('fa-IR')` → «۱۴۰۵ مرداد ۲۵». در پنل، تاریخ + ساعت + «۳ دقیقه پیش».
4. **مبلغ:** `۱۲٬۴۹۰٬۰۰۰ تومان` — جداکنندهٔ هزارگان فارسی، بدون اعشار.
5. **جهت متن مخلوط:** برای نام محصول لاتین داخل جملهٔ فارسی از `<bdi>` استفاده کن.
6. **فرم‌ها:** لیبل سمت راست، الزامی با ستارهٔ سرخ در ابتدای لیبل (RTL).
7. **اسکرول افقی** کاروسل‌ها از راست به چپ؛ نقطه‌های اندیکاتور هم راست‌به‌چپ.
8. **ورودی تلفن:** پیش‌فرض `09` و ماسک `0912 345 6789`.

## ۳. چیدمان فروشگاه

### ۳.۱ دسکتاپ — سه ستون (الهام: اینستاگرام دسکتاپ)

```
┌──────┬───────────────────────────────┬──────────────────┐
│ ریل  │        ستون فید (630px)        │  ریل کنار (320px) │
│ 76px │   هدر چسبان + استوری + پست‌ها  │  سبد + فعالیت زنده │
└──────┴───────────────────────────────┴──────────────────┘
```

| ناحیه | عرض | محتوا |
|---|---|---|
| ریل ناوبری | 76px (بازشدنی به 244px) | لوگو، خانه، اکسپلور، کالکشن‌ها، دایرکت (با بج)، سبد (با بج)، پروفایل. پایین: تم تاریک، زبان، «فروشنده شو» |
| ستون فید | 470–630px (max) | هدر چسبان صفحه، استوری‌ها (۸۰px)، کارت پست (max 630px)، فاصلهٔ ۲۴px بین پست‌ها |
| ریل کنار | 320px، چسبان | ۱) کارت سبد (تعداد، جمع، «پرداخت») ۲) «فعالیت زنده» ۳) «پیشنهاد امروز» ۴) فوتر لینک‌ها |

**نکتهٔ تمایز:** در اینستاگرام این ستون «پیشنهاد کاربران» است؛ اینجا **سبد + فعالیت + پیشنهاد** است. این تغییر، ستون را از تزئینی به ابزار تبدیل می‌کند.

### ۳.۲ موبایل — تک‌ستونی (الهام: اینستاگرام موبایل)

- هدر بالا (56px، چسبان): لوگو راست، آیکون جست‌وجو + دایرکت + سبد چپ. با اسکرول، هدر شفاف می‌شود و فقط در اسکرول رو به بالا کامل ظاهر می‌شود.
- **نوار پایین (64px + safe-area)** ۵ آیتم: خانه · اکسپلور (ذره‌بین) · **خرید/سبد (مرکز، آیکون گرادیانی)** · دایرکت · پروفایل.
- استوری‌ها: ۹۰px ارتفاع، حلقه ۶۴px، اسکرول افقی.
- کارت پست: تمام‌عرض، بدون حاشیهٔ کناری؛ رسانه ۱:۱ یا ۴:۵.
- **دکمهٔ خرید چسبان در پایین** هنگام دیدن پست در شیت: قیمت راست، «افزودن به سبد» چپ (ارتفاع 52px).

### ۳.۳ بریک‌پوینت‌ها

| نام | عرض | چیدمان |
|---|---|---|
| `xs` | < 480 | موبایل، تک‌ستون، نوار پایین |
| `sm` | 480–767 | موبایل بزرگ، همان |
| `md` | 768–1023 | تبلت: ریل آیکونی + فید، ریل کنار پنهان (سبد به‌صورت شیت) |
| `lg` | 1024–1439 | سه‌ستون کامل، ریل بسته |
| `xl` | ≥ 1440 | سه‌ستون، ریل بازشده (244px) |

## ۴. آناتومی کامپوننت‌های کلیدی

### ۴.۱ کارت پست (PostCard) — قلب محصول

```
┌──────────────────────────────────────┐
│ [آواتار] نام فروشگاه ✓  · ۲۴m      ⋯ │  ← هدر 56px
├──────────────────────────────────────┤
│                                      │
│            رسانه (1:1 یا 4:5)        │  ← تصویر/ویدیو/کاروسل
│           [چیپ تخفیف ۲۰٪]  [♥]       │  ← overlay
│                          ● ○ ○       │  ← اندیکاتور کاروسل
├──────────────────────────────────────┤
│ نام محصول (H3، ۲ خط)          ★ ۴٫۶ │
│ ۱۲۴ خریدار · موجودی: ۱۲ عدد          │  ← ردیف اعتماد 13px
│ ▁▁▁▁▁ توضیحات ۳ خطی … «بیشتر»        │  ← متن clamp با دکمه
│ [رنگ: مشکی ▾] [سایز: M ▾]            │  ← انتخاب‌گر تنوع inline
│ ۲٬۴۹۰٬۰۰۰  ~۳٬۲۰۰٬۰۰۰~    [افزودن به سبد] │  ← نوار خرید 64px
├──────────────────────────────────────┤
│ ♥ ۲٬۳۴۱   💬 ۸۷   ↗ اشتراک   🔖 ذخیره │  ← اکشن‌بار 48px
│ [آواتار] به بهرام: سایز ۴۲ داره؟ …   │  ← پیش‌نمایش ۲ کامنت
│ مشاهدهٔ همهٔ ۸۷ کامنت                │
└──────────────────────────────────────┘
```

**قواعد:**
- تصویر **همیشه** با `aspect-ratio` ثابت تا پرش چیدمان نداشته باشیم (CLS=0).
- روی هاور دسکتاپ: کارت ۲px بالا می‌رود + سایهٔ e2 + دکمهٔ خرید از ۹۰٪ به ۱۰۰٪ کدری می‌رسد.
- آیکون قلب: دابل‌تپ روی رسانه = لایک با انیمیشن قلب بزرگ (مثل اینستاگرام) — اما اگر کاربر مهمان باشد، لایک محلی ذخیره و پس از لاگین سینک می‌شود.
- «افزودن به سبد» اگر تنوع اجباری داشته باشد، ابتدا شیت انتخاب را باز می‌کند؛ اگر تک‌تنوع باشد مستقیم اضافه می‌کند + توست «به سبد اضافه شد · مشاهدهٔ سبد».
- اگر ناموجود: دکمه به «اطلاع از موجودی» تغییر می‌کند (ثبت ایمیل/شماره → اعلان تلگرام).

### ۴.۲ حلقهٔ استوری / کالکشن

- قطر ۶۴px (موبایل) / ۶۶px (دسکتاپ)، حلقهٔ ۳px گرادیان با فاصلهٔ ۲px.
- «دیده‌شده» → حلقه خاکستری. «دارای آیتم جدید» → نقطهٔ برند.
- زیر حلقه: نام کالکشن، یک خط، ۱۱px.
- برای «حراج زنده»: حلقهٔ قرمز تپنده + بج «LIVE».
- داخل استوری: نوار پیشرفت سگمنتی بالا، تپ راست/چپ = قبلی/بعدی، نگه‌داشتن = توقف، سوایپ پایین = بستن. هر اسلاید می‌تواند یک **کارت محصول کوچک** با دکمهٔ خرید در پایین داشته باشد.

### ۴.۳ مودال پست (دسکتاپ) / شیت پست (موبایل)

**دسکتاپ:** مودال ۱۱۰۰×۷۰۰ (max 90vh)، دو ستون ۶۰/۴۰:
- **ستون چپ (رسانه):** پس‌زمینهٔ تیره، کاروسل با فلش، شمارنده، زوم روی کلیک، تامبنیل‌های پایین.
- **ستون راست:** هدر فروشگاه (آواتار، نام، دکمهٔ فالو)، بخش قابل‌اسکرول: عنوان، امتیاز، توضیحات بازشو، تنوع‌ها، **کارت قیمت چسبان** (پایین ستون)، آکاردئون ارسال/مرجوعی، لیست کامنت‌ها، نوار کامنت‌نویسی چسبان پایین.

**موبایل:** شیت تمام‌صفحه با انیمیشن از پایین؛ ترتیب: رسانه → نوار قیمت و خرید → عنوان → توضیحات بازشو → تنوع → کامنت‌ها → نوار کامنت پایین. کشیدن به پایین (drag-down) = بستن، با حفظ موقعیت اسکرول فید.

**دسترس‌پذیری:** focus trap، `Esc` = بستن، بازگشت فوکوس به کارت پست، `role="dialog" aria-modal="true"`.

### ۴.۴ توضیحات بازشو (Description Expander) — الزام صریح کارفرما

سه سطح افشا:

| سطح | محل | محتوا |
|---|---|---|
| **L0 — پیش‌نمایش** | کارت پست | ۳ خط با `line-clamp`، پایان با «…» و دکمهٔ «بیشتر» |
| **L1 — بازشده** | همان‌جا، expand درجا | متن کامل (تا ۱۲۰۰ کاراکتر) با انیمیشن ارتفاع + دکمهٔ «کمتر» |
| **L2 — شیت کامل** | دکمهٔ «جزئیات کامل» | شیت/مودال با ۴ تب: مشخصات · راهنمای سایز · ارسال و مرجوعی · پرسش‌ها |

**جزئیات پیاده‌سازی:**
- تشخیص نیاز به دکمه: اگر ارتفاع متن > ۳ خط (`scrollHeight` vs `clientHeight`) → دکمه نمایش داده شود؛ در SSR با شمارش تقریبی کاراکتر + `ResizeObserver` تصحیح شود.
- حفظ موقعیت اسکرول هنگام باز/بسته شدن (بدون پرش).
- متن از HTML سانیتایز‌شده یا Markdown محدود (bold, list, link) رندر می‌شود.
- «بیشتر» با `aria-expanded` و `aria-controls`.
- در L2، بخش «پرسش‌های پرتکرار دربارهٔ این کالا» از کامنت‌های پرلایک استخراج می‌شود (فاز ۲ با AI).

### ۴.۵ سیستم کامنت (کامل، کارکردی)

**قابلیت‌ها:**
- کامنت سطح ۱ (ریپلای تخت با `@نام`، بدون تودرتویی بی‌نهایت) — مثل اینستاگرام.
- لایک روی کامنت (optimistic), شمارش، «قلب» با انیمیشن.
- **ری‌اکشن سریع:** ♥ 👍 🔥 ❓ («قیمتش چنده؟») — حداکثر ۱ ری‌اکشن فعال.
- **منشن** `@` با autocomplete کاربران و پاسخ رسمی فروشگاه (بج «فروشنده»).
- **نشان «خرید تأییدشده»** برای کسانی که آن SKU را خریده‌اند (سبز، با تیک).
- **سنجاق (Pin)** تا ۳ کامنت توسط ادمین/پشتیبان (مثلاً «سایزبندی این مدل کوچک است»).
- **پرسش خرید (Buyer Question):** کامنت با `intent=question` → در تب «پرسش‌ها» و در صف پشتیبانی پنل ظاهر می‌شود و SLA ۲ ساعته دارد.
- **رسانه در کامنت:** آپلود عکس (حداکثر ۱ عکس، ۵MB) → پایهٔ تب «تگ‌شده‌ها».
- **ویرایش/حذف:** تا ۱۵ دقیقه پس از ثبت (ویرایش با برچسب «ویرایش‌شده»).
- **گزارش:** دلیل‌های استاندارد (اسپم، توهین، تبلیغ، نامرتبط) → صف مدیریت در پنل.
- **مرتب‌سازی:** مرتبط‌ترین (پیش‌فرض: سنجاق‌شده + خریداران تأییدشده + پرلایک) · جدیدترین · پرسش‌ها.
- **بارگذاری تدریجی:** ۱۰ کامنت اول، «مشاهدهٔ بیشتر» یا اسکرول بی‌نهایت با cursor.
- **Real-time:** کامنت‌های جدید با SSE؛ شمارندهٔ لایو بدون رفرش.
- **قواعد ضد آزار:** rate-limit (۵ کامنت در دقیقه)، فیلتر کلمات، shadow-ban برای اسپم، الزام لاگین برای کامنت (برخلاف خرید).
- **حالت مهمان:** می‌تواند بخواند؛ برای نوشتن، مودال ورود OTP.

**ساختار بصری هر کامنت (RTL):**
```
[آواتار 32px]  نامکاربر ✓خریدار   · ۲ ساعت پیش      ♥ ۱۲
               متن کامنت، حداکثر ۴ خط با «بیشتر» …
               پاسخ دادن · گزارش            [🏷 سنجاق]
               └─ پاسخ فروشگاه (پس‌زمینهٔ --ink-100، بج «فروشنده»)
```

### ۴.۶ نوار خرید و کارت قیمت

- قیمت فعلی: `--ink-900`, ۱۸px/800. قیمت قبلی: خط‌خورده، `--ink-400`, ۱۳px. درصد تخفیف: چیپ `--buy-500` سفید.
- «۳ عدد در انبار»، «ارسال امروز اگر تا ۱۸:۰۰ سفارش دهید» با آیکون ساعت.
- دکمهٔ اصلی: پر، `--buy-500`، ارتفاع ۴۸px، تمام‌عرض در موبایل.
- دکمهٔ ثانویه: «افزودن به علاقه‌مندی» (قلب خطی) و «مشاورهٔ خرید» (باز کردن دایرکت).

### ۴.۷ این‌باکس / دایرکت (روح تلگرام)

- دسکتاپ: لیست گفت‌وگو (۳۲۴px) + پنل چت. موبایل: لیست → چت (استک).
- حباب‌ها: مشتری `--ink-100` راست، فروشگاه `--buy-500` سفید چپ... (RTL: پیام خودم سمت چپ در RTL؟ قاعده: پیام خودم همیشه در لبهٔ «شروعِ» کاربر یعنی راست با رنگ برند؛ پیام دیگران چپ و خاکستری.)
- **کارت‌های غنی داخل چت:** سفارش (`#KIA-671670` با وضعیت و مبلغ)، فاکتور PDF، لینک پرداخت، کارت محصول («همین را می‌گفتی؟»)، درخواست آدرس.
- تایپینگ، دیده‌شده، پاسخ سریع از پیش‌نویس، برچسب گفت‌وگو (VIP، شکایت، مرجوعی)، تخصیص به پشتیبان، انتقال به همکار.
- حالت «بات» و «انسان» با سوییچ؛ پاسخ خودکار خارج از ساعت کاری.
