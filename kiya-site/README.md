# سایت مستقل کیا — شروع دوباره از خود قالب مالک

این پروژهٔ جدا داخل `kiya-site/` است. پروژهٔ قبلی ریشهٔ مخزن پاک/جابه‌جا نشده است.

## پوشه‌ها
- `template-original/`: کپی دقیق ۳۶ فایل قالب ارسالی؛ مرجع ثابت طراحی، نه برنامهٔ تولید. hashها در `template-manifest.json` هستند.
- `frontend/`: همان اجزا و چیدمان قالب، با Vite/React؛ مسیر توسعهٔ رابط جدید. فونت محلی، فایل‌های لوگوی جاافتاده، مسیریابی hash و جست‌وجوی فید اصلاح شدند.
- `backend/`: کپی مستقل هستهٔ Next/PostgreSQL فعلی، migrationها، تست‌ها، storage، مجوز و MFA و **تمام بستهٔ توضیحات/نقشه‌های قبلی در `backend/file/`**. دیتابیس محلی این پروژه port55433 دارد و با سایت قبلی مشترک نیست.
- `scripts/`: اجرای دو سرویس و بررسی دست‌نخوردن اصل قالب.

## اجرای مستقل
Node22 لازم است. در همین پوشه:
```sh
npm run install:all
npm --prefix backend run db:local
```
پس از آماده‌شدن دیتابیس، در ترمینال دوم:
```sh
npm --prefix backend run db:migrate
npm --prefix backend run db:seed
npm run dev
```
رابط جدید روی3100 و بک‌اند روی3101 اجرا می‌شود. مرورگر API را با مسیر نسبی `/api` از proxy رابط می‌گیرد؛ آدرس localhost بک‌اند به مرورگر خارجی داده نمی‌شود. secretها در فایل ignored خود backend هستند؛ فایل env ریشه را کپی نکنید.

```sh
npm run test:template
npm run build
node frontend/tests/browser.mjs
```
آزمون مرورگر به دو سرویس روشن و نصب dependencyهای backend نیاز دارد.

## مرز فعلی: هنوز فروشگاه کامل تولید نیست

ظاهر از خود قالب است، نه بازسازی تقریبی قبلی. اما داده‌ها و عملیات داخل StoreContext قالب هنوز نمونهٔ مرورگری هستند؛ انتخاب نقش در قالب مجوز واقعی نیست. بنر دائمی این را اعلام می‌کند. پرداخت نهایی عمداً بسته شده و سفارش پرداخت‌شده/کسر موجودی جعلی تولید نمی‌شود. حساب مدیر واقعی قبلی یا SMS/درگاه/Neon/Cloudflare در این کپی ساخته نشده است.

دکمهٔ «مشاهده کاتالوگ متصل به دیتابیس» یک اتصال واقعی GET به بک‌اند مستقل دارد؛ خطا را با seed مرورگر پنهان نمی‌کند. سایر بخش‌های قالب هنوز نباید اتصال سروری فرض شوند. جزئیات و مسیر کامل بعدی در `IMPLEMENTATION.md` است. تحویل این مرحله ادعای تکمیل FULL نیست.
