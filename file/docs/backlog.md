# بک‌لاگ (کارهای خارج از اسکوپ فازهای فعلی)

> ایجنت‌ها هر ایدهٔ خارج از اسکوپ را اینجا ثبت می‌کنند؛ حذف نمی‌کنند.

## فروشگاه
- [ ] جست‌وجوی تصویری (آپلود عکس → کالای مشابه)
- [ ] مقایسهٔ محصولات (تا ۳ مورد، جدول تفاوت)
- [ ] پیش‌سفارش و دراپ محدود با شمارنده
- [ ] کیف پول و اعتبار هدیه
- [ ] باشگاه مشتریان: امتیاز، سطح، دعوت دوستان
- [ ] باندل «این را با هم بخر» با تخفیف ترکیبی
- [ ] نظرات ویدیویی خریداران
- [ ] حالت «حراج زنده» با شمارنده و افزایش خودکار قیمت
- [ ] پخش زنده (Live Shopping)

## پنل
- [ ] ادیتور بصری صفحهٔ فرود (Landing Builder)
- [ ] قوانین قیمت‌گذاری خودکار (مثلاً زیر قیمت رقبا)
- [ ] پیش‌بینی موجودی با میانگین فروش ۳۰ روز
- [ ] داشبورد «کدام پست چقدر فروخت» با انتساب دقیق
- [ ] مدیریت چند انبار/شعبه و انتقال بین آن‌ها
- [ ] برنامهٔ وفاداری کارکنان و پورسانت
- [ ] گزارش مالی سازگار با نرم‌افزار حسابداری (سپیدار/هلو)

## اجتماعی و پیام
- [ ] مارکت‌پلیس چندفروشنده با پنل مستقل و تسویه
- [ ] برنامهٔ همکاری (Affiliate) با لینک اختصاصی و کمیسیون
- [ ] پشتیبانی چندزبانه و مسیر escalation
- [ ] بات هوشمند پاسخ‌گو روی پایگاه دانش محصولات
- [ ] کمپین چندکاناله با A/B تست و بهینه‌سازی خودکار
