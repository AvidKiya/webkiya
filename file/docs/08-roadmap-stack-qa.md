## ۴. مقیاس‌پذیری (Scalability)

### ۴.۱ سطوح مقیاس

| سطح | ترافیک | دایرکتوری | اقدام لازم |
|---|---|---|---|
| S0 | < 5k بازدید/روز | ۱ سرور + DB مشترک | کافی برای MVP |
| S1 | 5k–50k | Vercel + Neon | افزودن ISR، CDN تصاویر، ایندکس‌های فید |
| S2 | 50k–500k | + Redis/Queue مستقل + read replica | کش فید، precompute counters، جست‌وجو → Meilisearch |
| S3 | > 500k | چند‌منطقه، CDN لبه، sharding بر storeId | پیش‌محاسبهٔ فید per-user، جداسازی سرویس پیام |

### ۴.۲ گلوگاه‌ها و راه‌حل از روز اول

| گلوگاه | راه‌حل در MVP |
|---|---|
| فید بی‌نهایت | cursor-based + ایندکس `(status, publishedAt)` + کش ۶۰ ثانیه‌ای |
| شمارندهٔ لایک/کامنت | denormalized + `+1` در تراکنش + job اصلاح شبانه |
| موجودی/oversell | قفل ردیف + شرط `stock >= qty` + رزرو ۱۰ دقیقه |
| تصاویر | R2 + CDN + ۴ اندازه + AVIF + blurhash |
| صف کمپین | کارگر جدا با rate-limit و retry |
| جدول‌های پنل | صفحه‌بندی سرور + virtualization (نه بارگیری همه) |
| مسیرهای پول | تراکنش + idempotency-key |
| بار دیتابیس از آمار | جدول `DailyStat` پیش‌محاسبه‌شده به‌جای aggregation زنده |

### ۴.۳ بودجهٔ کارایی (Performance Budget)

- JS کلاینت صفحهٔ فید < ۱۸۰KB gzip (بدون vendor تحلیل).
- LCP < 2.5s / INP < 200ms / CLS < 0.05 در موبایل متوسط و 4G.
- تصویر کارت پست < ۱۲۰KB (AVIF، ۶۴۰px).
- فونت: فقط Vazirmatn subset فارسی، `font-display: swap`، preload وزن ۴۰۰ و ۷۰۰.
- بدون CLS: همهٔ مدیاها با `aspect-ratio` و اسکلتون با ابعاد دقیق.

## ۵. تست و تضمین کیفیت

### ۵.۱ هرم تست

```
        e2e (Playwright)  ~۱۵ مسیر حیاتی
      integration          API + سرویس‌ها + DB تست
    unit (Vitest)          منطق دامنه، RBAC، فرمت‌ها
```

### ۵.۲ ۱۵ مسیر e2e اجباری
1. خرید مهمان از فید تا پرداخت موفق · 2. خرید با تنوع و کوپن · 3. پرداخت ناموفق و بازیابی
4. ثبت کامنت + لایک + ریپلای · 5. ورود ادمین و ساخت محصول · 6. تغییر موجودی و Audit
7. تغییر وضعیت سفارش و اعلان · 8. بازپرداخت با تأیید دوم · 9. تلاش SUPPORT برای ساخت محصول (403)
10. انبارگردانی و تأیید · 11. ارسال کمپین تستی · 12. اتصال تلگرام (mock) و دریافت اعلان سفارش
13. جست‌وجوی فارسی با «ي/ك» عربی · 14. بازکردن «بیشتر» و شیت جزئیات کامل · 15. RTL/LTR مخلوط (نام لاتین در کامنت)

### ۵.۳ چک‌لیست لانچ (۴۰ آیتم، خلاصه‌شده)
**امنیت:** HTTPS/HSTS · CSP · rate-limit ورود/OTP/کامنت · سانیتایز HTML · CSRF · مجوز سرور برای هر مسیر پنل · 2FA ادمین · بکاپ تست‌شده · حذف کلیدها از ریپو · لاگ PII.
**داده:** snapshot قیمت · تراکنش موجودی · idempotency پرداخت · مهاجرت تست‌شده · seed جدا از production.
**تجربه:** ۵ حالت هر صفحه · موبایل واقعی تست‌شده · ارقام/تاریخ فارسی همه‌جا · صفحهٔ ۴۰۴ و ۵۰۰ فارسی · لینک‌های شکسته.
**محتوا/SEO:** متا همهٔ صفحات · schema.org · sitemap · OG image · متن حقوقی (قوانین، حریم، مرجوعی) · متن تماس/درباره.
**عملیات:** مانیتورینگ خطا · هشدار نرخ خطای پرداخت · داشبورد سلامت · on-call و runbook · تلفن/پیام پشتیبانی فعال.
**حقوقی:** مالیات و فاکتور · شرایط مرجوعی · رضایت اتصال تلگرام · سیاست حریم خصوصی مطابق الزامات.
