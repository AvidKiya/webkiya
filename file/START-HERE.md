## وضعیت واقعی
**به‌روزرسانی اجرا:** اپ مرحلهٔ دوم با PostgreSQL، نشست سروری و مدیریت پایه در ریشهٔ repo ساخته شده است؛ هنوز FULL یا آمادهٔ فروش نیست. [گزارش فعلی](docs/22-backend-foundation.md) و [گزارش تاریخی مرحلهٔ اول](docs/21-implementation-progress.md) و README ریشه مرجع وضعیت فعلی کد هستند؛ این پوشه همچنان بستهٔ مشخصات است.

اسناد، لوگوها، config عمومی، env الگو، skill و پرامپت به هم ارجاع داده شده‌اند. اپلیکیشن/درگاه/ربات واقعی در این مخزن پیاده‌سازی یا متصل نشده‌اند. این بسته ورودی ساخت است، نه خروجی ساخت. «کامل» یعنی قرارداد تحویل FULL ثبت شده، نه تضمین اینکه یک ایجنت در یک پاسخ همهٔ آن را بدون کلید و تأیید مالک تمام کند.

بررسی بسته: `python3 file/scripts/validate_package.py` از ریشهٔ مخزن، یا `python3 scripts/validate_package.py` از داخل همین پوشه.
