## داده و حدود اعتماد
همهٔ کالاها/قیمت‌ها sample؛ تصویرها از screenshotهای مرجع crop شده و اصل عکس production نیستند. محتوای برند از لوگوی مالک مشتق وب شده و فایل‌های اصلی باقی‌اند. هیچ secret واقعی، fake login، نقش اداری یا قیمت عمده در JS/HTML نداریم. localStorage فقط برای رفتار UI است؛ جای order/stock/payment backend را نمی‌گیرد. این پیش‌نمایش noindex است و پرداخت واقعی ندارد.

## آزمون‌ها و شواهد اجرا
- typecheck و ESLint پاس.
- ۱۰ unit test برای catalog/cart و parser ذخیرهٔ محلی پاس.
- ۴ Playwright E2E در Chromium روی خروجی production پاس: پست/کامنت/reload/پاسخ/ذخیره/سبد، جست‌وجو/بیشتر/استعلام، موبایل/استوری/حالت خالی، 404 و تم با حفظ پس reload.
- build تولیدی پاس؛ بررسی بستهٔ اسناد پاس.
- بررسی overflow در ۵ عرض یادشده پاس؛ screenshot موبایل 390 و دسکتاپ 1440 بررسی شد. این نتیجه معادل ممیزی کامل AA یا سنجش Core Web Vitals نیست.
- `npm audit --omit=dev`: بدون vulnerability در زمان این مرحله. audit کامل ۵ یافتهٔ high در زنجیرهٔ dev-only eslint-config-next → fast-glob/micromatch/braces گزارش می‌دهد. downgrade خودکار ابزار به نسخهٔ ناسازگار انجام نشد؛ پیگیری patch قبل تحویل نهایی لازم است. lint فقط روی سورس مورد اعتماد اجرا شود.
- CI workflow نوشته شده؛ اجرای GitHub Actions در این مرحله ادعا نشده است.

## مشکلاتی که در همین اجرا رفع شد
- مجوز origin برای HMR هم preview و هم localhost/127.0.0.1؛ بدون آن hydration dev منتظر می‌ماند.
- ذخیرهٔ هم‌زمان کامنت محلی با external store برای جلوگیری از گم‌شدن در reload سریع، و جلوگیری از بازنشانی focus مودال هنگام تایپ.
- مدیریت ارتفاع کم sidebar برای دسترسی دکمهٔ تم؛ 404 واقعی برای مسیرهای تعریف‌نشده؛ تم پس reload حفظ می‌شود.
