## تعریف محصول
«کیا ویترین» نام کاری یک **فروشگاه تک‌فروشنده** با رابط اجتماعی فارسی است؛ نه کپی برند اینستاگرام و نه یک پیام‌رسان عمومی. کشف کالا از فید، استوری و اکسپلور انجام می‌شود. تجربهٔ خرید، مشخصات، ارسال و مرجوعی حرفه‌ای است، اما پوستهٔ بصری تمام صفحات فروشگاه همچنان اجتماعی و یکپارچه می‌ماند؛ صفحهٔ محصول نباید ظاهر یک سایت جداگانهٔ دیجی‌کالایی پیدا کند. تلگرام فقط الهام تعامل و یک اتصال اختیاری است؛ خرید و پشتیبانی نباید به داشتن حساب تلگرام وابسته باشند.

## تصمیم‌های پایهٔ اجرایی
- تک‌فروشنده در V1؛ نام Store و ساختار قابل توسعه ممکن است، اما ادعای tenant isolation بدون storeId و تست مجاز نیست.
- PostgreSQL 16؛ TypeScript strict؛ Next.js App Router و React سازگار، با نسخهٔ پایدار و پشتیبانی‌شده در روز ساخت. نسخه و patch واقعی در lockfile و ADR ثبت شود؛ عبارت قدیمی Next.js 15 الزام به نسخهٔ آسیب‌پذیر نیست.
- Route Handlers برای API عمومی؛ Server Actions پنل فقط adapter روی همان سرویس دامنه. tRPC، چند ORM و دو موتور صف هم‌زمان اضافه نشوند.
- صف MVP: pg-boss در worker مستقل؛ SSE فقط اگر محیط استقرار پشتیبانی کند، در غیر این صورت polling کنترل‌شده. Docker/VPS با web و worker جدا، خط مبنای استقرار پیشنهادی است؛ تغییر نیاز به ADR دارد.
- پول: Decimal(14,0) تومان؛ API رشتهٔ رقم لاتین مانند `"1450000"`، واحد `TOMAN`. فقط adapter درگاه در صورت نیاز ریال را با ضرب دقیق در ۱۰ می‌سازد. هرگز float.
- UTC در DB با `@db.Timestamptz(3)`؛ نمایش Asia/Tehran و جلالی. ارقام ورودی فارسی/عربی نرمال شوند.
- مرور و سبد بدون ورود؛ ثبت سفارش با شمارهٔ OTP-تأییدشده، بدون فرم عضویت اجباری. «مهمان بدون تأیید شماره» در V1 نداریم.
- فقط OWNER نقش می‌سازد/ویرایش/تخصیص می‌دهد؛ ADMIN کارکنان عملیاتی را در حدود مجوز مدیریت می‌کند، نه نقش‌ها و اسرار خام را.
- مجوز نوشتن کارکنان با مجوز دامنه؛ مشتری با احراز هویت و مالکیت منبع. برای خرید عمومی نباید permission اداری لازم باشد.
- قیمت، موجودی، سفارش، پرداخت و دسترسی منبع حقیقت سرور دارند. Optimistic UI فقط حالت موقت است؛ موفقیت خرید تا پاسخ سرور اعلام نمی‌شود.

## پوستهٔ واکنش‌گرا و هویت
- ۳۶۰ تا ۷۶۷: فید تک‌ستون، هدر ۵۶، تب‌بار پایین ۶۴ + safe-area؛ تصویر edge-to-edge، اهداف لمسی حداقل ۴۴.
- ۷۶۸ تا ۱۰۲۳: ریل راست ۷۲ و فید منعطف تا ۶۰۰؛ سبد drawer. اسکرول افقی صفحه ممنوع.
- ۱۰۲۴ تا ۱۴۳۹: ریل راست ۷۶، فید منعطف تا ۶۰۰، ابزار چپ تا ۲۸۰؛ فاصله و padding از فضای باقی‌مانده. ریل ابزار اگر جا نبود drawer می‌شود.
- ۱۴۴۰ به بالا: ریل راست ۲۴۴، فید تا ۶۳۰، ابزار چپ ۳۲۰. ترتیب RTL با logical properties، نه چپ/راست ثابت.
- محصول مستقل همان تایپوگرافی، ناوبری و اجزای فید را دارد؛ اطلاعات خرید دقیق و لایه‌ای است، نه کپی ظاهر دیجی‌کالا.
- نام‌ها، لوگو و آیکون‌های اختصاصی برند نهایی شوند؛ نشان رسمی اینستاگرام/تلگرام به‌عنوان برند سایت استفاده نشود.
- رنگ CTA باید AA را پاس کند؛ برای متن سفید کوچک، `#EF4056` بدون سنجش قابل قبول نیست. گزینهٔ پیشنهادی `#C92340` و بررسی نهایی با axe/contrast checker.
- آمار فروش/بازدید و کمبود موجودی فقط از دادهٔ واقعی؛ فعالیت فردی صرفاً با رضایت و ناشناس‌سازی. عدد تصادفی یا فوریت جعلی ممنوع.

## معیار تحویل
دمو، staging و production سه سطح جدا هستند. تحویل production فقط پس از عبور ماتریس سند ۱۲، تست درگاه sandbox و واقعی کم‌مبلغ با اجازهٔ مالک، بازیابی بکاپ، تنظیم دامنه و تأیید محتوای حقوقی ممکن است. برآورد زمان/هزینهٔ سند ۰۸ فرض برنامه‌ریزی است، نه قیمت سرویس یا تعهد زمانی تأییدشده.
